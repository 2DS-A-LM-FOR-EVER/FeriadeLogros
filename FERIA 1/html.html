¡Bienvenido a HTML! 🌐

HTML es el lenguaje de marcado con el que se construyen las páginas web. No "programa" cosas: usa etiquetas como <h1> o <p> para decirle al navegador qué es cada parte de la página.

Con HTML defines:

  • títulos, párrafos y listas
  • imágenes y enlaces
  • la estructura de cualquier sitio web
