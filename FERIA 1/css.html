¿Qué es CSS? 🎨

CSS significa Cascading Style Sheets (hojas de estilo en cascada). Es el lenguaje que le dice al navegador cómo se ve una página web.

¿Cuándo se inventó?

Lo propuso Håkon Wium Lie en 1994, mientras trabajaba con Tim Berners-Lee en el CERN. En diciembre de 1996 el W3C publicó CSS1 como estándar. Después llegaron CSS2 (1998) y CSS3, que se divide en módulos y sigue creciendo hasta hoy.

¿Para qué sirve?

  • Cambiar colores, fuentes y tamaños.
  • Controlar espacios, bordes y fondos.
  • Acomodar elementos (Flexbox, Grid).
  • Adaptar la página a celulares y pantallas grandes (responsive).
  • Crear animaciones y transiciones.

La idea clave

HTML es el esqueleto (qué contiene la página) y CSS es la ropa (cómo se ve). Separarlos permite cambiar todo el diseño sin tocar el contenido.

Una regla se escribe así: selector { propiedad: valor; }
